# Вариант 2 — Объём файлов журналов

Администратор оценивает объём файлов с расширением log по готовому каталогу, без чтения диска.

names и sizes имеют одинаковую длину; sizes — размеры в КБ не меньше 0. Сложить размеры имён, заканчивающихся на .log без учёта регистра по OrdinalIgnoreCase. Имя x.log.bak не подходит. Пустой каталог даёт 0.

В текущей версии ошибки исправлены. Исходная версия с ошибками сохранена в ветке `review-base`.
Замечания ревью описаны в `review.md`, исправления — в `resolution.md`.

Для запуска требуется .NET SDK 9.0 или новее с поддержкой целевой платформы .NET 9.

Запуск: `dotnet run --project ReviewLab.csproj`

- T01: Сумма; ожидается [30].
- T02: Регистр; ожидается [7].
- T03: Ложное расширение; ожидается [0].
- T04: Единственный; ожидается [5].
- T05: Пустой; ожидается [0].

Дополнительные тесты U01–U04 проверяют смешанный регистр, ложные расширения,
обработку последнего элемента и неизменность входных массивов при повторном вызове.
При успешном запуске все девять тестов выводят PASS, итог: `Failed: 0`.
